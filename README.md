# fullstack_developer_capstone

## Dealership Review Application

A full-stack web application developed as part of the Full Stack Software Developer Capstone Project. The application allows users to view car dealerships, read customer reviews, submit new reviews with sentiment analysis, and manage user authentication (login, logout, registration).

### Tech Stack
- **Backend:** Django Framework, Python, Express.js / Node.js
- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Database:** MongoDB / SQLite
- **Deployment & Containers:** Docker, IBM Cloud

### Features
- View all car dealerships across different states.
- Search and filter dealerships by ID or State.
- View dealership reviews and post new reviews.
- Complete User Authentication system (Sign Up, Sign In, Sign Out).
